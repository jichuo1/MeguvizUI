# 文本预计算可选适配

通过 `-PenableText=true` 启用该模块。它只使用 Android SDK 与 UI core，不引入额外文本库。

`PrecomputedTextBinding` 使用 UI 会话独占 `text` 槽，要求调用方提供真正异步的 executor。默认关闭预计算，只有显式启用且达到最小长度的纯 `String` 标签在 API 28 及以上才调用系统 `PrecomputedText`。API 27、短文本、带 span、`EditText` 和有 filters 的控件使用普通 setter；带 span 的输入会复制为 `SpannedString`，span 对象自身的可变状态仍由调用方负责。

每次任务捕获完整平台文本度量参数、配置、密度、资源令牌与绑定代际。实际写入前再核对参数：参数在提交后发生变化时（例如控件挂载后才解析出 RTL 布局方向），旧结果不会被应用，而是用当前参数重新计算最新文本，最多重试两次；重试用尽，或在帧到来前参数又变化时，改用普通 setter 写入同一文本，保证最新内容一定显示。字体或主题由外部原位变更时，调用方仍应先调用 `invalidate()` 或相应资源权威的失效方法。旧计算不会被抢占，队列仅保留最新待办，不在测量时等待 Future。

普通文本状态可合并；编辑或带 span 的 setter 保留命令语义。状态与命令通道没有全局顺序，混用时应由应用控制写入顺序。会话 rebind 或释放时自动关闭本绑定；主动关闭也会释放属性槽。

性能准入与字体/方向/断行/语言矩阵见 [P2 使用说明](../docs/p2.md)。
